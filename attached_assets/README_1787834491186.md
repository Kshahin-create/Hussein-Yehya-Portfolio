# سجل الأثر القيادي — حسين يحي

هذه صفحة Static مستقلة مبنية بملفات **HTML وCSS وJavaScript فقط**. وهي رسالة تقدير مختصرة من **سارة سامح حسين**، عضو فريق Edu‑Tech، عن أثر حسين يحي في تنظيم العمل والمتابعة والالتزام بالمواعيد.

## التشغيل

افتحي `index.html` في متصفح حديث. لا تحتاج الصفحة تثبيت أدوات أو خادماً محلياً.

استخدمي زر **EN / عربي** للتبديل بين العربية العامية القاهرية والإنجليزية، وزر **فاتح / داكن** للتبديل بين الوضعين. تحفظ الصفحة الاختيارات على المتصفح تلقائياً.

## المحتويات

| الملف أو المجلد | وظيفته |
| --- | --- |
| `index.html` | المحتوى العربي والإنجليزي وهيكل الصفحة |
| `style.css` | التنسيق، الاستجابة للشاشات، والوضعان الفاتح والداكن |
| `script.js` | التبديل بين اللغة والوضع، والقائمة المتجاوبة والحركة الخفيفة |
| `assets/` | الصور ورمز الهوية المستخدم في الصفحة |

المعلومات المهنية العامة مستلهمة من البورتفوليو المنشور علناً على [husseinyehya.com](https://husseinyehya.com/).
