# نسخة Static — حسين يحيى حسين

هذه نسخة مستقلة من الموقع مبنية باستخدام **HTML وCSS وJavaScript فقط**. لا تحتاج إلى Node.js أو أي عملية بناء.

## التشغيل

افتح ملف `index.html` مباشرةً في المتصفح. ولأفضل توافق مع المتصفحات الحديثة، يمكن فتح المجلد بواسطة أي خادم ملفات بسيط؛ لكن ذلك غير مطلوب للمشاهدة العادية.

## الملفات

| الملف أو المجلد | الغرض |
|---|---|
| `index.html` | بنية الصفحة والمحتوى العربي. |
| `styles.css` | التصميم الداكن، التجاوب، والحركة. |
| `script.js` | قائمة الموبايل وكشف المحتوى أثناء التمرير. |
| `assets/` | كل الصور المستخدمة في الصفحة محلياً. |

> يتم تحميل خطوط عربية من Google Fonts عند وجود اتصال بالإنترنت. إن لم يكن متاحاً، يستخدم الموقع خطوط النظام كبديل.
